# Signal Studio

> A tiny control room for live signals.

Signal Studio is a small dashboard for watching system state changes as motion and color instead of plain logs.

## Concept

- Interactive dashboard for live style signals  
- Focus on low cognitive load  
- Shows patterns instead of raw noise  

## Planned tech

- React + TypeScript  
- Vite  
- Framer Motion  
- Node.js (mock WebSocket server)
